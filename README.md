# امیرکالا — فروشگاه (Node.js + SQLite)

## ساختار
- `server.js` — بک‌اند Express: محصولات، سفارش، ورود مدیر، پنل ادمین، آپلود عکس، لاگ، بک‌آپ روزانه
- `public/` — فرانت‌اند (`index.html` + `app.js`)
- `deploy.sh` — نصب کامل روی اوبونتو/دبیان (Node، Nginx، فایروال، سرویس systemd، SSL)
- داده‌ها در `data/` (یا `DATA_DIR`) ذخیره می‌شوند: `shop.db`، `uploads/`، `backups/`

## اجرای محلی
    npm install
    ADMIN_PASSWORD='یک-رمز-قوی-حداقل-۱۰-حرف' npm start
    # http://localhost:3000   پنل: http://localhost:3000/#admin

## نصب روی سرور
    scp -r amirkala-shop root@SERVER_IP:/root/
    ssh root@SERVER_IP
    cd /root/amirkala-shop && bash deploy.sh yourdomain.com you@email.com
(قبلش رکوردهای A دامنه و www را به IP سرور وصل کنید.)

## تنظیمات (`/etc/amirkala.env`)
`ADMIN_USER`، `ADMIN_PASSWORD` (فقط هنگام ساخت اولین ادمین)، `CARD_NUMBER` (برای کارت‌به‌کارت)، `SITE_URL`، `PORT`.
تغییر رمز: `cd /opt/amirkala && sudo -u amirkala DATA_DIR=/var/lib/amirkala npm run passwd -- admin NEWPASS`

## امنیت
رمز با bcrypt، کوکی httpOnly/SameSite=Strict، محدودیت تعداد تلاش ورود و سفارش، Helmet، قیمت‌ها فقط سمت سرور محاسبه می‌شوند، آپلود فقط JPG/PNG/WebP تا ۳MB.
پیشنهاد: ورود SSH با رمز را غیرفعال و با کلید وارد شوید؛ فایل `.env` را در گیت نگذارید.

## قابلیت‌های نسخه‌ی ۲
- ثبت‌نام/ورود مشتری (کوکی جدا از ادمین) و تاریخچه‌ی سفارش‌ها در «حساب من»؛ ثبت سفارش نیاز به ورود دارد
- کد تخفیف (درصدی) — از پنل مدیر بسازید؛ مبلغ تخفیف همیشه سمت سرور حساب می‌شود. هیچ کد پیش‌فرضی ساخته نمی‌شود
- دسته‌بندی محصولات، نظر و امتیاز (هر کاربر یک نظر برای هر محصول؛ ویرایش‌پذیر)
- ویرایش محصول در پنل (نام، قیمت، تخفیف، موجودی، دسته، عکس) + آپلود عکس
- خروجی اکسل سفارش‌ها: `/api/admin/orders.csv` (دکمه‌ی «خروجی اکسل» در پنل)
- محصول بدون عکس، آیکون وکتور نمایش می‌دهد (بدون ایموجی)
- ورود مدیر: `/#admin` با نام کاربری و رمز (حتماً رمز را نگه دارید؛ پنل شماره و آدرس مشتری‌ها را نشان می‌دهد)

## ارتقا از نسخه‌ی قبلی روی سرور
فایل‌های جدید را روی `/opt/amirkala` کپی کنید (پوشه‌ی `data` را دست نزنید) و `systemctl restart amirkala`.
دیتابیس موجود خودکار مهاجرت می‌شود و محصولات اولیه دسته‌بندی و آیکون می‌گیرند.

## هنوز انجام نشده
درگاه پرداخت آنلاین (طبق درخواست)، فونت خودمیزبان (الان از Google Fonts)، ایمیل/پیامک اطلاع‌رسانی، چندکاربره‌ی ادمین، بازیابی رمز مشتری، کد تخفیف مبلغ‌ثابت از UI.
